# Local scientific papers

This directory contains metadata for scientific papers used by the project.

Expected local document:

- `chen2020_parameterization.pdf`
- DOI: https://doi.org/10.1149/1945-7111/ab9050

Publisher PDFs are local inputs and are excluded from Git. They must not be
redistributed until their applicable licence and redistribution rights have
been verified.

The extracted parameter registry must preserve the source page, table,
original parameter name, original value and original unit.
